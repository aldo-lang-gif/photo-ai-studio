PHOTO AI STUDIO — versione 0.4

Contenuto:
- Regolazioni locali di luminosità, contrasto, saturazione e nitidezza.
- Miglioramento automatico locale di base (non è AI generativa).
- Confronto prima/dopo, filtri e salvataggio.
- Registrazione del service worker per cache offline dopo il primo accesso.
- Sezione informativa per le future funzioni AI generative.

PUBBLICAZIONE
Caricare e sostituire nella cartella principale del repository:
index.html, manifest.webmanifest, sw.js, icon.svg.
LEGGIMI.txt può essere sostituito facoltativamente.

IMPORTANTE
Questa versione NON implementa ancora rimozione intelligente, generazione di sfondi,
modifica di pose o abbigliamento, né miglioramento AI generativo. Queste funzioni
richiedono un servizio online dedicato e un backend sicuro. Non inserire chiavi API
nel codice pubblicato su GitHub Pages.
Le immagini vengono elaborate localmente nel browser; il codice statico del sito
è pubblico perché GitHub Pages usa questo repository pubblico.
