PHOTO AI STUDIO 0.5

CONTENUTO
- index.html: nuova schermata Studio IA e strumenti locali.
- sw.js: cache offline aggiornata alla versione 0.5.
- manifest.webmanifest: impostazioni PWA.
- icon.svg: icona.

COSA FUNZIONA ORA
- Apertura foto, anteprima, confronto prima/dopo e salvataggio.
- Regolazioni locali di luminosità, contrasto, saturazione e nitidezza.
- Filtri tono caldo e bianco e nero.
- Scelta del tipo di modifica IA, descrizione testuale e preparazione/copia delle istruzioni.

COSA NON È ANCORA ATTIVO
Le modifiche generative (rimozione oggetti, cambio sfondo, vestiti, pose e miglioramento generativo) NON vengono ancora eseguite. La versione 0.5 prepara le istruzioni e l'interfaccia; il motore locale va installato e collegato quando il PC sarà disponibile. Non è presente alcun invio automatico di foto a servizi esterni.

AGGIORNAMENTO
1. Apri il repository GitHub photo-ai-studio.
2. Carica i file estratti nella root del repository.
3. Conferma il commit. I file con lo stesso nome verranno sostituiti e GitHub conserverà la cronologia.
4. Apri https://aldo-lang-gif.github.io/photo-ai-studio/
5. Se appare ancora la versione precedente, chiudi e riapri la pagina o svuota la cache del sito.

IMPORTANTE
Non inserire chiavi API o password in questi file o nel repository pubblico.
